# 교사용 작업 지시서 — 우리 학교 3D 전시관 만들기

> 준비물: **구글 계정 하나**, 인터넷이 되는 컴퓨터(크롬 권장). 그 밖의 가입·설치는 없습니다.
> 걸리는 시간: 약 10분. 한 줄씩 하고 ☐에 표시하세요.

만들기 화면: **https://parkdongbae.github.io/school-3d-artcenter/?make**
(아래 1~3단계가 이 화면에 그대로 나옵니다. 이 문서는 같은 내용을 더 자세히 적은 것입니다.)

---

## 1단계. 구글 설문지 준비 (5분)

- ☐ **1-1.** 구글에 로그인합니다.
- ☐ **1-2.** 만들기 화면의 초록색 **설문지 사본 만들기** 버튼을 누르고, 나오는 화면에서 **사본 만들기**를 누릅니다.
  → 질문이 다 들어 있는 설문지가 내 구글 드라이브에 생깁니다.
- ☐ **1-3.** 설문지 맨 위 제목을 우리 학교에 맞게 고칩니다. 예) `○○중학교 미술 작품 제출`
  ⚠ **질문의 순서와 개수는 바꾸지 마세요.** (학번 → 성명 → 작품1 제목 → 내용 → 이미지 … 순서로 읽습니다)
- ☐ **1-4.** 설문지 위쪽 **응답** 탭 → **Sheets에 연결** → **만들기**를 누릅니다.
  → 응답이 쌓이는 **구글 시트**가 새 탭으로 열립니다. 이 탭을 닫지 마세요.
- ☐ **1-5.** 그 구글 시트 오른쪽 위 **공유** 버튼 → "일반 액세스"의 **제한됨**을 눌러 **링크가 있는 모든 사용자**로 바꿉니다. 역할은 **뷰어** 그대로 → **완료**.
- ☐ **1-6.** [구글 드라이브](https://drive.google.com)를 열어 **`설문지 제목 (File responses)`** 폴더를 찾습니다.
  폴더에 마우스 오른쪽 버튼 → **공유** → **공유** → 똑같이 **링크가 있는 모든 사용자 · 뷰어**로 바꿉니다.
  (학생이 올린 사진이 들어가는 폴더입니다. 이걸 안 하면 사진이 안 보입니다.)
- ☐ **1-7.** 설문지 **설정 → 응답**에서 **응답 수정 허용**을 켭니다. (학생이 나중에 작품을 고칠 수 있게)

## 2단계. 구글 시트 주소 붙여넣기 (1분)

- ☐ **2-1.** 1-4에서 열린 구글 시트 탭으로 가서, 맨 위 **주소창의 글자를 전부 복사**합니다. (주소창 클릭 → Ctrl+C)
- ☐ **2-2.** 만들기 화면의 **② 구글 시트 주소 붙여넣기** 칸에 붙여넣고(Ctrl+V) **연결 확인**을 누릅니다.
- ☐ **2-3.** 초록색 **✅ 연결되었습니다**가 나오면 성공입니다.

| 빨간 글씨가 나오면 | 이렇게 하세요 |
|---|---|
| "시트를 읽지 못했습니다" | 1-5(시트 공유)를 다시 확인합니다. |
| "설문지 주소가 아니라…" | 설문지가 아니라 **구글 시트** 탭의 주소를 복사해야 합니다. |
| "작품 사진이 보이지 않습니다" | 1-6(사진 폴더 공유)를 다시 확인합니다. |

## 3단계. 전시 이름 적고 주소 만들기 (2분)

- ☐ **3-1.** **전시 제목 첫째 줄**(필수), 둘째 줄, **학교 이름**을 적습니다. 오른쪽 현수막 미리 보기가 바로 바뀝니다.
- ☐ **3-2.** 노란색 **🎉 전시관 주소 만들기** 버튼을 누릅니다.
- ☐ **3-3.** **주소 복사**를 눌러 메모장·한글 문서에 붙여넣어 보관합니다. **QR 코드 그림 저장**도 눌러 둡니다.
- ☐ **3-4.** **전시관 열어 보기**를 눌러 우리 학교 제목이 보이는지 확인합니다.

## 4단계. 시험해 보고 알리기

- ☐ **4-1.** 설문지 오른쪽 위 **보내기**(또는 게시) → 링크를 복사해, 선생님이 먼저 그림 한 장으로 시험 제출을 해 봅니다.
- ☐ **4-2.** 2분쯤 뒤 전시관 주소를 새로고침(F5)해서 시험 작품이 걸렸는지 봅니다.
- ☐ **4-3.** 학생에게는 **설문지 링크**(작품 내는 곳)와 **전시관 주소**(구경하는 곳) 두 가지를 알려 줍니다. → [학생 제출 안내문](학생-제출-안내문.md)
- ☐ **4-4.** 시험 제출은 구글 시트에서 그 줄을 지우면 전시관에서도 사라집니다.

## 전시 중·전시 후에 할 일

| 하고 싶은 일 | 방법 |
|---|---|
| 잘못 올라온 작품 내리기 | 구글 시트에서 그 학생의 줄을 지웁니다. (2분 뒤 반영) |
| 작품 제목·설명 고치기 | 구글 시트에서 그 칸을 직접 고칩니다. |
| 전시 제목 바꾸기 | 만들기 화면에서 다시 적고 주소를 새로 만들어 다시 알립니다. |
| 학교 로고 넣기 | 로고 그림을 구글 드라이브에 올리고 "링크가 있는 모든 사용자"로 공유 → 그 주소를 만들기 화면 **③ 더 꾸미기**에 붙여넣고 주소를 새로 만듭니다. |
| 감상평을 한곳에 모으기 | 전시관에서 **F9** → **감상평** → "웹 앱 주소 만드는 방법"을 따라 만든 주소를 **③ 더 꾸미기**에 붙여넣고 주소를 새로 만듭니다. (안 하면 감상평은 쓴 기기에만 남습니다) |
| 제출 마감하기 | 설문지 **응답** 탭에서 **응답 받기**를 끕니다. |
| 전시 끝내기 | 구글 시트와 사진 폴더의 공유를 **제한됨**으로 되돌립니다. 전시관에 작품이 더 이상 보이지 않습니다. |

## 꼭 지킬 것 (개인정보)

- 전시관 주소를 아는 사람은 **학생 이름·학번·작품**을 볼 수 있습니다. 학교의 개인정보·초상권 동의 절차를 따르세요.
- 구글 시트에는 전시에 필요 없는 정보(전화번호 등)를 적지 마세요. 시트 전체가 "링크가 있는 사용자"에게 보입니다.
- 학생 얼굴이 나온 사진은 올리지 않도록 안내하세요.
