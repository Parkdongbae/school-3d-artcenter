    감상평

    감상평은 기본적으로 쓴 기기에만 저장됩니다. 아래에 Apps Script 웹 앱 주소를 넣고 모든 기기에 적용하면, 모든 학생의 감상평이 구글 시트 한 곳에 한 줄씩 모입니다.

    웹 앱 주소 만드는 방법 (처음 한 번 · 약 5분)
    1. 새 구글 시트 만들기를 누르고, 왼쪽 위 제목을 감상평 모음처럼 바꿉니다.
    2. 시트 위쪽 메뉴에서 확장 프로그램 → Apps Script를 누릅니다. 새 탭에 코드 편집기가 열립니다.
    3. 편집기에 있는 글자(function myFunction() {…})를 모두 지우고, 아래 코드를 복사해 붙여넣은 뒤 저장(디스크 모양 아이콘 또는 Ctrl+S)을 누릅니다. 
      function doPost(e) {
  var lock = LockService.getScriptLock();
  lock.waitLock(10000);
  try {
    var sh = SpreadsheetApp.getActiveSpreadsheet().getSheets()[0];
    if (sh.getLastRow() === 0) {
      sh.appendRow(['받은 시각', '학번', '이름', '감상평', '작품 제목', '작가', '작가 학번', '전시실']);
    }
    var d = JSON.parse(e.postData.contents);
    sh.appendRow([new Date(), t(d.sid), t(d.name), t(d.text), t(d.artTitle), t(d.artist), t(d.artistSid), t(d.room)]);
  } finally {
    lock.releaseLock();
  }
  return ContentService.createTextOutput('ok');
}
// 글자를 그대로 적기 (=, + 로 시작해도 수식으로 바뀌지 않게)
function t(v) {
  v = String(v == null ? '' : v).slice(0, 1000);
  return /^[=+\-@]/.test(v) ? "'" + v : v;
}
    4. 오른쪽 위 파란 배포 버튼 → 새 배포를 누릅니다.
    5. 왼쪽 유형 선택 옆 톱니바퀴 → 웹 앱을 고릅니다.
    6. 설정을 이렇게 맞추고 배포를 누릅니다.
      • 다음 사용자 인증 정보로 실행: 나
      • 액세스 권한이 있는 사용자: 모든 사용자 (학생이 로그인하지 않아도 보낼 수 있게)
    7. 액세스 승인 → 내 구글 계정 선택. "Google에서 확인하지 않은 앱" 화면이 나오면 왼쪽 아래 고급 → (프로젝트 이름)(으)로 이동 → 허용을 누릅니다. 선생님이 직접 만든 코드라서 나오는 안내이니 걱정하지 않으셔도 됩니다.
    8. 웹 앱 URL(https://script.google.com/…/exec로 끝나는 주소)의 복사를 누르고 완료를 누릅니다.
    9. 복사한 주소를 아래 칸에 붙여넣고 모든 기기에 적용을 누릅니다. 2~3분 뒤 작품에 감상평을 하나 써 보고, 시트에 한 줄이 생기는지 확인하세요.

    · 학교(구글 워크스페이스) 계정에서 모든 사용자가 보이지 않으면, 개인 Gmail 계정으로 시트를 만들어 주세요.
    · 코드를 고쳐 다시 배포할 때는 배포 → 배포 관리 → 연필(수정) → 버전: 새 버전 → 배포를 누르면 주소가 바뀌지 않습니다. 새 배포를 다시 누르면 주소가 바뀌므로 아래 칸에 새 주소를 다시 넣어야 합니다.
    · 감상평 시트는 학생에게 공유하지 마세요. 시트가 비공개여도 감상평은 잘 들어옵니다.
